\# 🎙️ Local AI Text-to-Speech (TTS) Player



Intel Core i9 프로세서 및 NVIDIA GeForce RTX 4070 GPU 환경에 최적화된 로컬 딥러닝 기반 한국어 음성 합성(TTS) 프로그램입니다. Coqui TTS(`XTTS-v2`) 모델과 CUDA 가속을 사용하여 텍스트를 고품질 한국어 음성으로 변환하고 즉시 출력합니다.



\---



\## 🛠️ 주요 기능 및 특징

\- \*\*GPU 가속 지원\*\*: NVIDIA CUDA를 활용한 빠른 음성 합성 처리

\- \*\*고품질 한국어 음성\*\*: Coqui TTS 의 `XTTS-v2` 모델 기반의 자연스러운 한국어 음성 변환

\- \*\*간편한 CLI 인터페이스\*\*: 콘솔 환경에서 직접 문장을 입력받아 음성 출력



\---



\## 💻 요구 사항 (Prerequisites)

\- Python 3.10 이상

\- NVIDIA GPU (CUDA 지원 카드, 예: RTX 4070) 및 최신 GPU 드라이버
